# Contributing

Thanks for helping improve the LEAN Process Improvement Agent.

## Before opening a pull request

1. Use only fictional or explicitly public examples.
2. Do not add production exports, office documents, connection files, screenshots of internal systems, or organization-specific records.
3. Keep generated recommendations advisory and subject to human review.
4. Run `./scripts/privacy-check.ps1` from PowerShell.
5. Explain the coaching behavior changed and how you tested it.

Contributions that could expose private data will be closed until the material is removed from the full Git history.
